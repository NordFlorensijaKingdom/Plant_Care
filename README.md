##Plant Care Assistant##


​Plant Care Assistant is a cross-platform mobile application built with React Native and Expo. It is designed to help plant enthusiasts—from beginners to experts—track their plants' health, set flexible care schedules, and maintain a beautiful digital garden.


​🌿 Current Features (Phase 1 & 2 Completed)


​📋 Plant Management & Profiles




​Detailed Profiles: Add plants with names, species, location (room/windowsill), and purchase/replanting dates.


​Photo Gallery: Each plant has its own dedicated photo album to track growth over time.


​Care History: A log of all actions (watering, spraying, fertilizing) with the ability to edit or undo entries.




​⏰ Smart Notifications & Scheduling




​Flexible Reminders: Set watering and spraying intervals in hours or days.


​"Today" Dashboard: A centralized screen showing all tasks due today with quick actions (Done/Skip).


​Advanced Notifications: Supports "Quiet Hours," snooze functionality, and mass management of alerts.


​Custom Reminders: Add one-time or yearly reminders (e.g., for seasonal fertilizing).




​🗓️ Care Planning




​Care Templates: Quick presets for different plant types (Succulents, Tropical, Flowering, etc.).


​Care Calendar: Visual weekly/monthly view of upcoming and past tasks using react-native-calendars.




​🎨 Personalization & UX




​Custom Themes: Change text colors, UI elements, and app-wide background wallpapers in settings.


​Note System: Add and edit notes for each plant (Read-only mode by default for better data safety).


​Offline First: All data is stored locally on the device.




​🛠 Tech Stack




​Framework: React Native (Expo)


​Icons: Lucide-react-native


​Storage: AsyncStorage / SQLite (Local)


​UI: Custom styles with theme support

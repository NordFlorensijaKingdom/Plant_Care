# Дизайн: скрытие шкал ухода + цвет фона (PlantCare)

## Контекст

В приложении PlantCare уже есть настройки на уровне растения:
- `wateringEnabled` / `mistingEnabled` (включение ухода)
- интервалы `wateringInterval` / `mistingInterval`

Также есть настройки темы через `ThemeContext` (цвета текста, акцента, карточек, фон-картинка).

## Цели

1) Дать возможность в настройках профиля растения “убрать шкалу” полива и/или опрыскивания.
2) Добавить функцию изменения цвета фона приложения (один цвет глобально).

## Нецели

- Не добавлять новые типы ухода или новые экраны.
- Не менять логику расписаний/уведомлений, кроме визуального скрытия элементов и блокировки действий.
- Не вводить отдельные настройки для light/dark (только один выбранный цвет).

## Требования и поведение

### 1) Скрытие шкал и кнопок ухода

**Источник правды:** уже существующие флаги в `Plant`:
- `wateringEnabled`
- `mistingEnabled`

**Поведение при выключении (подтверждено):**
- “Скрыть полностью”: соответствующая шкала/таймер скрывается везде.
- Кнопки действий (Water/Mist) для этого ухода также скрываются.

#### Экран списка (карточка растения)

- Если `wateringEnabled === false`:
  - не показывать строку прогресса/таймера полива
  - не показывать кнопку быстрого действия “полить”
- Если `mistingEnabled === false`:
  - не показывать строку прогресса/таймера опрыскивания
  - не показывать кнопку быстрого действия “опрыскать”

#### Экран деталей растения

- Если `wateringEnabled === false`:
  - не показывать care-card “Watering” целиком
- Если `mistingEnabled === false`:
  - не показывать care-card “Mist” целиком
- Если оба выключены:
  - не показывать весь блок care-cards

### 2) Цвет фона приложения (один цвет)

**Источник правды:** `ThemeContext`.

Добавить поле:
- `backgroundColor: string | null`

Поведение:
- Если `backgroundColor` задан — это становится базовым фоном приложения (замена `colors.background`).
- Если `backgroundColor === null` — используется системный фон из текущей палитры (`constants/colors.ts`).
- Если включена фон-картинка (`backgroundImage`) — она остается выше, как сейчас. Цвет фона нужен на случай отсутствия фон-картинки, и как базовый fallback.

## UI/UX изменения

### Настройки приложения

В `Settings` добавить новую секцию “Background color”:
- набор пресетов (как у других секций)
- кнопка “Custom” через существующий `ColorPickerModal`
- Reset к системному фону (`backgroundColor = null`)

### Настройки растения

UI уже содержит переключатели `wateringEnabled` / `mistingEnabled` в Add/Edit Plant. Поведение меняется визуально на карточках и на деталях.

## Хранение данных

- `backgroundColor` сохраняется вместе с другими настройками темы через текущий AsyncStorage-ключ `plant_care_theme_v2` (с миграцией по умолчанию).
- В `Plant` ничего нового добавлять не требуется (используются существующие поля).

## План изменений (на уровне файлов)

1) `ThemeContext`:
   - добавить `backgroundColor` в `ThemeSettings`, defaults, сеттер, сохранение/миграция.
2) `useColors`:
   - возвращать `background` как `theme.backgroundColor ?? palette.background`.
3) `Settings`:
   - секция выбора backgroundColor.
4) `PlantCard`:
   - скрыть прогресс-блоки и скрыть кнопки Water/Mist согласно флагам.
5) `Plant Details`:
   - скрыть care-cards по флагам.

## Критерии приемки

- При `wateringEnabled=false` нигде не видно шкалы/таймера полива и нет кнопки “полить”.
- При `mistingEnabled=false` нигде не видно шкалы/таймера опрыскивания и нет кнопки “опрыскать”.
- Выбранный цвет фона сохраняется и применяется после перезапуска приложения.
- При `backgroundColor=null` фон соответствует системной палитре.
- При включённых “обоях” приложение продолжает показывать фон-картинку как и раньше.
